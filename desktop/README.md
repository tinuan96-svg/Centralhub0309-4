# CentralHub Windows x64

This is the Windows 64-bit desktop shell for CentralHub.

- Loads the production CentralHub site at https://centralhub.network.
- Keeps login/session data persistent on the laptop.
- Closing the window minimizes CentralHub to the Windows system tray.
- Microphone permission is allowed for CentralHub so the existing web voice fallback can be used.
- The current Windows build focuses on the full dashboard/admin experience. Android-only native features such as the current Shruthi Live Web computer-control bridge remain on Android until their Windows-native bridge is added.
