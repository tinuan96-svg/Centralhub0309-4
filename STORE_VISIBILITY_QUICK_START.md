# Store Visibility System - Quick Start

## 🎯 What It Does

Simple system to control which products appear in each store. Products are visible in all stores by default. Admin can hide specific products from specific stores.

---

## 📍 How to Access

**Method 1:** Sidebar → Inventory → Store Visibility

**Method 2:** Inventory page → Click "👁️ Store Visibility" button (top-right)

---

## 🚀 3-Minute Quick Start

### Step 1: Select a Store

1. Open Store Visibility page
2. Use dropdown at top to select store
3. View statistics showing total/visible/hidden products

### Step 2: View Product Grid

You'll see a grid:
- **Rows** = Products
- **Columns** = Stores
- **Toggles** = Visibility switches

**Green toggle** = Product visible in that store
**Gray toggle** = Product hidden from that store

### Step 3: Toggle Visibility

Click any toggle to hide/show a product in that store.

**Example:**
- Product "Nike Shoes" has green toggle under "Store A"
- Click toggle → turns gray
- Nike Shoes is now hidden from Store A

---

## 💡 Common Tasks

### Hide One Product from One Store

1. Find product in grid (use search if needed)
2. Look at store's column
3. Click toggle → it turns gray
4. Done! Product hidden.

**Time: 5 seconds**

---

### Hide Multiple Products from One Store

1. Select store from dropdown
2. Check checkboxes for products to hide
3. Click "🚫 Hide from [Store]" button
4. Done! All selected products hidden.

**Time: 30 seconds for 20 products**

---

### Show All Hidden Products

1. Select store from dropdown
2. Check "Show hidden only" filter
3. Click "Select All"
4. Click "✅ Show in [Store]" button
5. Done! All hidden products now visible.

**Time: 15 seconds**

---

### Find Where a Product is Visible

1. Use search box to find product
2. Look across the row at all store columns
3. Green toggles = stores where it's visible
4. Gray toggles = stores where it's hidden

**Time: 10 seconds**

---

## 🎮 Using the Grid

### Search Bar
Type product name to filter the grid. Only matching products shown.

### Store Filter
Select a specific store to focus on just that store's visibility.

### Show Hidden Only
Toggle this ON to see only products hidden from selected store.

### Select All / Deselect All
Use these buttons to quickly select/deselect all visible products for bulk actions.

---

## 📊 Understanding Statistics

When you select a store, you see:

- **Total Products** - All products in database
- **Visible** - Products currently shown in this store
- **Hidden** - Products explicitly hidden from this store
- **Default Visible** - Products visible by default (no override set)

---

## 🔄 Default Behavior

### Important Rule

**Products are visible in ALL stores by default.**

This means:
- ✅ New products appear everywhere automatically
- ✅ New stores see all products immediately
- ✅ No setup required
- ❌ You only hide products when needed

### Why This Matters

If you create a new product, it will automatically be visible in all stores. You don't need to "assign" it anywhere. You only use this system to HIDE products from specific stores.

## 🎯 Real-World Examples

### Example 1: Electronics Store

**Situation:** You have an electronics store that shouldn't show food products.

**Solution:**
1. Select "Electronics Store" from dropdown
2. Search for "food" or use category filter
3. Select all food products
4. Click "Hide from Electronics Store"
5. Done! Food products no longer appear in electronics store.

---

### Example 2: Flagship Store Only Product

**Situation:** You have a premium product that should only appear in your flagship store.

**Solution:**
1. Find the premium product in grid
2. Look at its row across all stores
3. Click toggles to turn them gray for all stores EXCEPT flagship
4. Leave flagship store's toggle green
5. Done! Product only visible in flagship.

---

### Example 3: Seasonal Cleanup

**Situation:** Winter is over, hide all winter products from summer stores.

**Solution:**
1. Select summer store from dropdown
2. Search "winter" or use category filter
3. Select all winter products
4. Click "Hide from [Summer Store]"
5. Repeat for other summer stores
6. Done! Winter products hidden from summer stores.

---

## ⚠️ Important Notes

### Note 1: Hidden = Not in Store Catalog

When you hide a product from a store, it will NOT appear in that store's product listings. Customers shopping at that store will not see the product.

### Note 2: Global Product Data Unaffected

Hiding a product from a store does NOT:
- Delete the product
- Change the product's price
- Change the product's inventory
- Affect other stores

It ONLY controls visibility in that specific store.

### Note 3: Can Unhide Anytime

You can always toggle visibility back on. Products are never permanently hidden.

### Note 4: Admin Always Sees Everything

Admin users (you) can always see ALL products in the visibility grid, even hidden ones. This is so you can manage visibility.

## 💪 Bulk Actions

### When to Use Bulk Actions

Use bulk actions when you need to hide/show many products at once.

**Don't:** Click 50 individual toggles ❌
**Do:** Select 50 products and use bulk hide button ✅

### How Bulk Actions Work

1. Check checkboxes for products (or use Select All)
2. Bulk action bar appears at top showing selection count
3. Click "Hide from [Store]" or "Show in [Store]"
4. System processes all changes
5. Page refreshes with updated grid

**Note:** Bulk actions work on the currently selected store only.

## 🚨 Troubleshooting

### "Product not showing in store"

**Check:** Is it hidden in the visibility grid?

**Fix:**
1. Find product in grid
2. Look at that store's column
3. If toggle is gray, click it to turn green
4. Product now visible

---

### "I hid a product but it still shows"

**Possible Causes:**
1. Wrong store selected
2. Toggle didn't save (network issue)
3. Cache needs refresh

**Fix:**
1. Verify correct store selected
2. Check toggle is gray
3. Refresh page
4. Check again

---

### "Can't find product in grid"

**Possible Causes:**
1. Filter is active
2. Wrong search term
3. Product doesn't exist

**Fix:**
1. Clear search box
2. Uncheck "Show hidden only"
3. Select "All Stores" from dropdown
4. Try searching again

## 🎯 Pro Tips

### Tip 1: Use Search

Don't scroll through 500 products. Use search to find what you need instantly.

### Tip 2: Filter by Store First

If you're managing one store, select it from dropdown first. Makes the grid easier to work with.

### Tip 3: Use Show Hidden Only

When cleaning up, use "Show hidden only" to see what you've hidden and potentially re-enable.

### Tip 4: Select All Carefully

"Select All" selects ALL VISIBLE products. If you have filters active, it only selects filtered products. Be careful with bulk actions on large selections.

### Tip 5: Refresh After Bulk Actions

The page refreshes automatically after bulk actions. Wait for it to complete before making more changes.
